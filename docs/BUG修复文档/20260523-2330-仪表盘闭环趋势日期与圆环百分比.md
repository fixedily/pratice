# BUG 修复报告

## 基本信息
- 日期：2026-05-23
- 报告人：Codex
- 模块/功能：前端检修总览 / 异常处理趋势 / 闭环推进状态
- 严重级别（低/中/高）：中
- 影响范围：仪表盘闭环总览趋势图和右侧完成率圆环展示
- 严重级别依据（是否阻断/可绕过/影响用户数）：不阻断业务操作，但会误导用户判断异常触发时间；100% 文案在圆环中心视觉越界，影响展示可信度。所有进入检修总览的用户均可见。

## 问题描述
- 期望结果：今天才触发并闭环的任务只应在今天所在时间桶出现；右侧圆环中心的 `100%` 应完整落在圆环内圈范围内。
- 实际结果：趋势图使用模拟走势，把单条今天触发的数据扩散到前几天；右侧圆环中心 `100%` 字号偏大，贴近或超出内圈边界。

## 复现步骤（必须可复现）
1) 打开前端 `/dashboard` 检修总览页面。
2) 使用一条 `created_at=2026-05-23T09:00:00`、`updated_at=2026-05-23T10:00:00`、状态为 `resolved/completed` 的闭环任务数据。
3) 查看“异常处理趋势”和“闭环推进状态”：趋势图前几天出现非真实数据，圆环中心 `100%` 视觉过大。

## 复现环境
- 设备/系统：Windows / Chromium Playwright
- 应用版本/配置：Next.js 前端，`NEXT_PUBLIC_API_BASE_URL=http://127.0.0.1:18000`
- 相关依赖或外部条件：Recharts 图表渲染；Dashboard API mock 数据

## 定位过程
- 关键线索：`buildTrendBuckets` 会根据当前状态和密度构造 `alertCurve`、`taskCurve`、`closedCurve`，不是按真实事件时间计数。
- 排查路径：定位 `frontend/features/dashboard/screens/dashboard-page.tsx` 中趋势数据生成函数；定位 `frontend/features/dashboard/components/charts.tsx` 中圆环中心百分比字号。
- 根因说明：趋势图为制造“走势”使用了模拟曲线，导致今天才发生的任务被绘制到过去日期；圆环中心百分比使用 `text-3xl`，在 `100%` 三位字符时超出内圆可读范围。

## 修复方案
- 修改点说明：趋势图改为按真实时间桶计数：`created_at` 计入告警触发，`updated_at` 计入诊断任务和闭环完成；圆环中心百分比改为较小字号并增加 `leading-none/tabular-nums`。
- 影响评估：趋势图不再展示模拟平滑走势，改为真实事件计数；仪表盘统计卡、阶段分布和风险任务逻辑不变。
- 风险点：如果后端只返回有限 recent 数据，趋势图仍受接口数据范围限制。
- 回滚方案：回退本次 dashboard 页面、charts 组件和对应 e2e 测试改动。

## 变更内容
